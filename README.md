# Kate's Planner

A calm task planner: By EOD, REAcT, Work, Athletics, Wellness and Michael.

- Live at https://katetwede-maker.github.io/planner-/
- Sign-in and syncing use Firebase (project `kate-s-planner`). Tasks live in Firestore under each user's own account, protected by the Firestore rules. Nothing personal is stored in this repository.
- `widget/Planner-EOD-widget.js` is the By EOD home-screen widget for the Scriptable app on iPhone.
